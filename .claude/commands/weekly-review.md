# Prepare the weekly approval meeting

Read CLAUDE.md first. Use the real names and arguments supplied by the operator. Never invent a record or evidence.

```bash

```

The command reads inbox, attention, workload and compliance. Present overdue decisions first, name each owner, then list the proposed follow-ups. Do not send them.
